# Безопасность

FontHub — тестовое self-hosted приложение для доверенной сети. Веб-интерфейс пока не имеет собственной авторизации. Не публикуйте его напрямую в Интернет: используйте VPN либо reverse proxy с авторизацией. Индексатор имеет отдельный API-токен, который не защищает страницы FontHub.

OTS проверяет структуру шрифта, но не заменяет изоляцию обработки и не гарантирует совместимость с Windows. Анализ fontTools пока не выполняется в отдельной песочнице. Docker Compose сохраняет данные в постоянных томах и по умолчанию публикует сайт только на localhost.

Если обнаружена уязвимость, не публикуйте ключи, личные шрифты, содержимое каталога или рабочие базы в issue. Приватный канал сообщения об уязвимости следует настроить владельцу репозитория до публичного выпуска; сейчас он не указан.
