# Работа над FontHub

Используйте Python 3.12+, Git и Node.js для JavaScript-проверки. Установка и Docker-развёртывание описаны в README.

## Проверки

Переносимые проверки не требуют скачанных или коммерческих шрифтов: smoke-тест генерирует собственный небольшой шрифт во временной директории.

```sh
python scripts/checks.py
node test_search.js
```

Запускайте команды установленным интерпретатором виртуального окружения. На Windows для полного набора, включая OTS, очереди, экспорт и аварийное восстановление:

```powershell
.venv/Scripts/python.exe scripts/checks.py --windows
```

Полный набор пока использует установленные в Windows Arial и Arial Bold и ожидает окружение `.venv` в корне проекта. Эти файлы не распространяются с репозиторием. Проверки `test_google_fonts.py` и `test_live_sources.py` являются отдельными интеграционными проверками; они не включены в offline CI и могут требовать опубликованных индексов или внешней сети.

## Изменения

Обновляйте README и соответствующие страницы wiki вместе с изменением схемы, очередей, адаптеров или пользовательского поведения. Сохраняйте оригиналы неизменными; не обходите OTS автоматически при отказе. Тестовые архивы и базы создавайте во временных директориях, не в рабочем `data`.

Не добавляйте реальные шрифты, каталог, ключи API и локальные настройки в Git. Синтетические fixture-данные адаптеров находятся в `tests/fixtures`, пример адаптера — в `examples/adapters`. Открытая лицензия проекта пока не выбрана.
