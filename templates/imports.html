Папка проверяется рекурсивно каждые пять секунд, даже при паузе. Копируйте большой файл с расширением .part и переименуйте после окончания копирования.

Сначала сохраняется оригинал, доступный для скачивания из задания. Полный анализ выполняется отдельной очередью: только после него шрифт появляется в поиске с готовым покрытием языков. Предпросмотр WOFF2 создаётся и проверяется OpenType Sanitizer отдельно. Задания каждой очереди обрабатываются по порядку постановки в очередь.

Ошибка предпросмотра не удаляет шрифт из архива. Ошибки приёма сохраняются в карантине. При ошибке анализа оригинал остаётся в архиве. Повторная обработка выполняется только по вашему нажатию.
